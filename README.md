# Abu Hamid Academy

Islamic education in Harehills, Leeds. Hosted on **GitHub Pages** at https://abuhamid.academy.

## Publishing
GitHub Pages publishes the `main` branch from the repository root. The `CNAME` file declares the custom domain. No Vercel hosting is used.

## Edit and build
`index.js` retains the original website source, styles, and embedded logo. Run `npm run build` with Node.js 20 or later to regenerate the five HTML pages and assets. No package installation is required. Commit the generated files to publish updates. `npm start` serves a local preview on http://localhost:4174.

`build-pages.mjs` creates the static GitHub Pages version, converts navigation to HTML file links, and replaces the registration form with the approved **Enrolment opening soon** notice.

## Enrolment
Registration is not open. The website does not collect form submissions. The email address and WhatsApp number are placeholders. A form service can be connected later when enrolment opens.
